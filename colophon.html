Technical Details

Clean HTML5

This website was hand-coded using clean HTML5(without CSS and JS). For example, the basic structure looks like this: 


<!DOCTYPE html>
<html lang="en">
<head>
    <title>RixFit</title>
</head>
<body>
</body>
</html>

The keyboard shortcut Ctrl + S was used to save files in the editor.

Used tools:

  • GitHub repository → Example: git add, git commit, git push, git status, git reset, git rm, git pull.
  • W3C for code validation → Example: take index.html and upload it to W3C validation, it shows mistakes, we fix it.
  • VS code main IDE for coding
