Before your first set

  1. Read the labelCheck the machine label. Ask a trainer if the purpose is unclear.
  2. Set it upAdjust the seat, pad or handle so your starting position is stable.
  3. Start lightChoose a light load and do one slow test repetition.
  4. Stay controlledKeep the movement smooth and stop if you feel sharp pain.
  5. Leave it cleanReturn the load and wipe the contact points after use.

Equipment terms

Names can differ between machines. Ask a trainer to show you the setup before using unfamiliar equipment. See also the club rules.
